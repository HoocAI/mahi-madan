# Mahi Madaan — Portfolio Landing Page

An interactive portfolio landing page built from the [Figma Design](https://www.figma.com/design/TB9rWcWaadWMSTnj9jmhju/Landing-Pages?node-id=1-2).

## Tech Stack'
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Google Fonts** (`Cormorant Garamond` & `Instrument Sans`)

## Features & Implementation Highlights
- **Typography & Aesthetics**: Faithful rendition of the design's editorial typography with Cormorant Garamond display headings and Instrument Sans body text.
- **Hero Section**: Large display typography, tagline, and the staggered signature brand monograms with the arch portrait frame.
- **About Section**: Multi-column editorial bio, statement headline, and arch silhouette.
- **Businesses & Ventures Grid**: Asymmetric 3-column masonry grid (desktop) and streamlined vertical list (mobile) showcasing the 6 ventures:
  - *The Velvet Veils* (Beauty / Skincare)
  - *King International* (Venture)
  - *Ayurvedic Magic* (Ayurveda / Wellness)
  - *Vaanipath* (Venture)
  - *Mahi Records* (Music / Entertainment)
  - *The Bebo Studio* (Fashion / Lifestyle)
- **Interactive Component States**: Primary button hover/focus/pressed states, card focus and hover treatments, copy-to-clipboard email interaction, and smooth section navigation.
- **Responsive Navigation**: Desktop navigation bar with active section indicator and full-screen mobile menu drawer.

## Running Locally

To start the local development server:
```bash
npm run dev
```

To build for production:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
